# enki landing page

A static page (`index.html`, `styles.css`) for the open-source scanner. It has
no backend, no forms, and no tracking.

## Deploy

- **GitHub Pages:** Settings → Pages → deploy from branch, folder `/site`.
- **Netlify / Cloudflare Pages:** publish directory `site`; no build step.
- **Self-host:** serve this directory with any static web server.
