# Trademark policy

The name **enki**, the enki wordmark, and the enki logo are trademarks of the
project maintainer. The Apache-2.0 license covers the source code, not the
marks.

## Allowed without permission

- Referring to the project by name in articles, talks, reviews, and
  comparisons.
- Stating that your product works with, integrates with, or is built on enki,
  in a factual and non-confusing way (for example, "an enki rule pack").
- Distributing unmodified release binaries and preserving their notices.
- Using the name in a repository fork, provided you make clear that it is a
  fork and not the official project.

## Not allowed without written permission

- Using the name or logo as the name or branding of your own product or
  service.
- Implying endorsement, sponsorship, or official status.
- Using the marks in a way that is likely to confuse users about the source of
  the software.
- Registering domains, social accounts, or package names that suggest official
  status.

## Forks

Forks must rename the project for user-facing branding if they make
substantial changes, and must not present themselves as the official release.
Attribution to the upstream project is welcome.
