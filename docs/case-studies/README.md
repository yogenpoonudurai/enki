# enki case studies

Three reference deployments, written as runnable field notes. They are
illustrative scenarios, not customer testimonials: every command works, the
outputs are representative, and the personas are generic.

| Post | Focus |

| [Developer laptop](laptop.md) | local AI runtimes, MCP configs, agent permissions, secrets |
| [GPU inference server](gpu-server.md) | exposed endpoints, OS/SBOM inventory, SIEM export, change control |
