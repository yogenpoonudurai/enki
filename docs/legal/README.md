# Legal documents (drafts)

> **Draft — not legal advice.** These documents are templates for the hosted
> service. Have qualified counsel in your jurisdiction review and complete them
> before taking payment or signing customers.

The open-source software is licensed under Apache-2.0 (`LICENSE`). These
documents cover the **hosted service only**.

Before publishing, fill every placeholder:

| Placeholder | Meaning |
|---|---|
| `[LEGAL ENTITY]` | Registered company or individual operating the service |
| `[ADDRESS]` | Registered address |
| `[JURISDICTION]` | Governing law and courts |
| `[CONTACT EMAIL]` | Privacy and legal contact |
| `[EFFECTIVE DATE]` | Date the document takes effect |
| `[LLM PROVIDER]` | Model provider used for hosted triage |
| `[HOSTING PROVIDER]` | Infrastructure provider |
| `[RETENTION]` | Audit-metadata retention period |
| `[SLA]` | Enterprise availability commitment, if any |
