# Support

## Using enki

- Start with [docs/quickstart.md](docs/quickstart.md) and
  [docs/getting-started.md](docs/getting-started.md).
- The rule catalog and data sources are in [docs/rules.md](docs/rules.md) and
  [docs/data-sources.md](docs/data-sources.md).
- CI setup (SARIF, thresholds, what a runner can and cannot see) is in
  [docs/ci-quickstart.md](docs/ci-quickstart.md).

## Bugs and feature requests

Open a GitHub issue using the templates. Include `enki version`, your OS and
architecture, the command you ran, and the relevant output. Redact secrets,
tokens, hostnames, and paths before posting.

## Security issues

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and use the
repository's private vulnerability reporting.

## Hosted service

The hosted service is a separate paid product. Use the support address
published on the service site for account, billing, and data questions.
Issue-tracker reports about the hosted service go through the same private
channel as security reports.

## What is not supported

- Findings about your own machine that enki correctly reports.
- Misconfiguration of third-party model providers or inference servers.
- Modified binaries or hand-edited state directories.
